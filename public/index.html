TrafficDash reads your PostHog and Stripe accounts directly and joins them on user_id. Every source card is built from your own traffic — nothing is assumed or filled in.

  1. Add a PostHog personal API key and project ID.
  2. Add a Stripe restricted key (rk_live, read-only).
  3. Make sure checkout sets metadata.user_id to the same id you pass to posthog.identify().
