Settings

Connect PostHog and Stripe. The dashboard reads both directly and joins them on user_id — nothing is stored anywhere but this machine.

PostHog

Not connected

Profile → Personal API keys → Create, with access to your project. The Project ID is in project settings.

Stripe

Not connected

Developers → API keys → Create restricted key. Grant exactly Checkout Sessions = Read, Events = Read, Charges = Read. Everything else None.

Two keys make the join work. On every Checkout Session, set metadata.user_id to the same id you pass to posthog.identify(), and metadata.posthog_distinct_id to posthog.get_distinct_id(). Send both when you have both — the second is the only thing that can attribute a guest checkout, which by definition has no user id.
